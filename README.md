# phriend-web

Marketing site for Phriend, a local-services marketplace in the Philippines where ID-verified adults offer guiding, photo and video, tutoring, driving and errand services by the hour. Live at [phriend.app](https://phriend.app).

## Part of Phriend

| Repo | What it is |
|---|---|
| phriend-web | Marketing site (phriend.app). This repo. |
| phriend-ui | Shared design tokens and web components, synced into the apps |
| phriend-ph | Next.js PWA (web.phriend.app) |
| phriend-api | FastAPI service (api.phriend.app) |
| phriend-admin | Ops moderation portal |
| phriend-expo | Android/iOS app |

## What's on the site

- Landing page (`/`)
- Services (`/services`, `/services/[activity]`) and occasions (`/occasions`, `/occasions/[occasion]`) landing pages
- Creators (`/creators`) and a creator card endpoint (`/creators/card`)
- Teams (`/teams`), Android (`/android`), Press (`/press`)
- Blog (`/blog`, `/blog/[slug]`), loaded from the API with a few posts in `app/blog/_posts`
- Safety, community guidelines, privacy, terms, delete-account
- `sitemap.xml`, `robots.txt`, web manifest, generated Open Graph images
- `llms.txt` and `llms-full.txt` (plain-text descriptions for LLM crawlers), in `public/`

## Tech stack

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4
- lucide-react, marked, sanitize-html
- `@next/third-parties` and Google Analytics (optional)

## Getting started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:3100.

Environment variables (all optional; set them in `.env.local`):

| Name | Purpose |
|---|---|
| `API_URL` | Base URL of the Phriend API. Defaults to `https://api.phriend.app`. |
| `API_SERVER_KEY` | Sent as the `x-phriend-app` header on server-to-server API calls. Without it, the API may reject requests from the site's server. |
| `NEXT_PUBLIC_GA_ID` | Google Analytics measurement ID. Analytics scripts are not loaded when unset. |

Blog, press and creator pages read data from the API, so they need a reachable `API_URL`.

## Scripts

## Project layout

```
app/          Routes, layout, sitemap, robots, manifest, OG images
components/   Page and UI components (ui.tsx is generated from phriend-ui)
lib/          Site constants, API access, blog, occasions, creator card
public/       Static files, llms.txt, llms-full.txt
scripts/      Maintenance scripts (CDN upload)
```

`app/phriend-ui.css` and `components/ui.tsx` are generated by phriend-ui; change them there, not here.

## Deployment

A standard Next.js app (`next build --webpack`, `next start`), deployed as a Hostinger Node.js web app that rebuilds on every push to `main`.
